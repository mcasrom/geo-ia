Init - Configuración del Sistema

⚙️ Configuración del Sistema GeoClaude4

Esta página contiene información sobre la configuración y uso del sistema de blog.

🚀 Comandos Principales

M-x ggeoclaude4-init-blog      ; Inicializar blog
M-x ggeoclaude4-new-post       ; Crear nuevo post
M-x ggeoclaude4-new-page       ; Crear nueva página
M-x ggeoclaude4-publish-blog   ; Publicar blog
M-x ggeoclaude4-menu           ; Menú interactivo

📁 Estructura de Directorios

~/GeoClaude4/
├── posts/          ; Posts del blog
├── pages/          ; Páginas estáticas
├── assets/         ; Recursos
│   ├── css/        ; Estilos
│   ├── js/         ; Scripts
│   └── images/     ; Imágenes
└── index.org       ; Página principal

🎯 Variables de Configuración

ggeoclaude4-blog-title           ; Título del blog
ggeoclaude4-blog-subtitle        ; Subtítulo
ggeoclaude4-blog-email           ; Email de contacto
ggeoclaude4-base-directory       ; Directorio base
ggeoclaude4-publishing-directory ; Directorio de publicación

📝 Formato de Posts

Los posts deben incluir:

  • #+TITLE: Título del post
  • #+DATE: Fecha de publicación
  • #+TAGS: etiquetas separadas por espacios
  • #+DESCRIPTION: Descripción breve

🖼️ Manejo de Imágenes

Use M-x ggeoclaude4-insert-and-copy-image para:

  • Copiar imágenes al directorio assets
  • Generar enlaces relativos automáticamente
  • Aplicar tamaños predefinidos según el nombre

📊 Estadísticas

Use M-x ggeoclaude4-get-blog-stats para ver estadísticas del blog.
